### 🛠️ Nelerle Uğraşıyorum?
- 🌐 **Full Stack Web Development:** Laravel ve PHP ile sağlam backend mimarileri kurarken, frontend tarafında Next.js, Blade ve Bootstrap 5 kullanarak kullanıcı dostu, responsive arayüzler tasarlıyorum.
- 📱 **Mobile Development:** React Native ile cross-platform uygulamalar geliştiriyor, MIT App Inventor ile hızlı prototipleme çözümleri üretiyorum.
- 💾 **Database & Architecture:** MySQL ve Eloquent ORM kullanarak ilişkisel veritabanı tasarımı yapıyor, verilerin güvenli ve performanslı bir şekilde işlenmesini sağlıyorum.
- 🔍 **Debugging & Maintenance:** Yazılım geliştirme sürecinde karşılaşılan hataları analiz edip optimize ediyor, Vite ve NPM gibi araçlarla modern geliştirme iş akışlarını yönetiyorum.
- 🤖 **AI Entegrasyonu:** Yerel modeller (Ollama/Qwen) ve WSL kullanarak, geliştirdiğim projelere yapay zeka destekli akıllı özellikler entegre ediyorum.
